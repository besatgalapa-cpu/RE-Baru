# Panduan Menjalankan Aplikasi Secara Offline di Komputer/Laptop

Aplikasi ini menggunakan 3 komponen:
1. **Frontend** (Tampilan Antarmuka)
2. **Backend** (Pemroses Data & Excel)
3. **MongoDB** (Penyimpan Data di Laptop Anda)

---

## Langkah 1: Persiapan 1x Saja di Komputer Anda
Download dan instal 3 program gratis berikut (cukup klik Next -> Next -> Finish):
1. **Node.js**: Unduh di `https://nodejs.org` (Pilih versi LTS)
2. **Python**: Unduh di `https://python.org` (Centang "Add Python to PATH" saat menginstal)
3. **MongoDB Community Server**: Unduh di `https://www.mongodb.com/try/download/community` (Pilih "Install as a Service" agar otomatis menyala setiap laptop hidup)

---

## Langkah 2: Menjalankan Aplikasi
Setelah kode ini Anda unduh ke folder laptop:
1. Buka folder aplikasi.
2. Klik ganda (Double-Click) file **`JALANKAN_APLIKASI.bat`**.
3. Aplikasi akan otomatis terbuka di browser dan **bisa dipakai 100% tanpa koneksi internet**.
